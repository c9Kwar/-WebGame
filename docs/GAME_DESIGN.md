# 잔향 서고 — 게임 설계와 밸런스

## 경험의 중심

“오늘 한 번 돌아온 것만으로 내 서고가 조금 더 좋아졌다.”

행동은 탐사 → 발견 → 복원의 세 가지로 시작합니다. 수집은 기록의 폭, 복원은 좋아하는 유물의 깊이, 연구는 모든 활동의 편안함을 넓힙니다. 이야기 보상은 숫자로만 성장하지 않도록 지역 수집과 연결합니다.

강화는 확정 성공합니다. 유물은 소실되지 않으며, 더 좋은 등급이 나오더라도 기존 유물은 도감 공명에 기여합니다. 유물을 3개만 골라 동행하기 때문에 복잡한 속성 상성이나 여러 장비 슬롯을 관리할 필요가 없습니다.

## 플레이 순환

1. 탐사지 선택. 한 번 열린 곳은 공명력이 낮아져도 다시 잠기지 않습니다.
2. 2.8초의 짧은 탐사. 유물 1개, 잉크, 잔향, 경험치를 항상 획득합니다.
3. 새로운 유물은 도감에 들어갑니다. 동행 칸이 비었다면 자동 장착됩니다.
4. 중복 유물은 해당 유물의 기억과 추가 잔향으로 전환됩니다.
5. 잉크·잔향으로 복원, 중복 기억으로 공명, 잉크로 영구 연구를 합니다.
6. 공명력 문턱을 넘으면 새 탐사지가 열리고, 같은 지역의 유물 3종을 모으면 이야기가 열립니다.

5회 연속 탐사는 화면을 보고 있을 때만 다음 탐사를 이어갑니다. 중지 버튼은 진행 중인 한 회를 마친 후 멈춥니다. 탭을 숨기면 다음 회차는 귀환 시 이어집니다.

## 자원

| 자원 | 획득 | 용도 |
| --- | --- | --- |
| 잉크 | 탐사, 여정 보상, 휴식 | 복원·영구 연구 |
| 잔향 | 탐사, 중복 추가 보상, 여정 보상, 휴식 | 복원 |
| 중복 기억 | 같은 유물 재발견 | 해당 유물 공명 |
| 경험치 | 탐사 | 서고지기 레벨·추가 공명력 |

최초 자원은 잉크 120, 잔향 12입니다. 첫 탐사에는 반드시 새로운 유물을 줍니다. 각 탐사는 무료이며 자원 부족으로 탐사 자체가 막히지 않습니다.

## 지역별 경제

| 지역 | 필요 공명력 | 기본 잉크 | 기본 잔향 | XP |
| --- | ---: | ---: | ---: | ---: |
| 비가 멎은 거리 | 0 | 32 | 3 | 20 |
| 새벽의 온실 | 160 | 58 | 5 | 28 |
| 무명의 극장 | 300 | 96 | 7 | 38 |
| 별을 읽는 탑 | 480 | 148 | 9 | 50 |
| 파도의 도서관 | 680 | 220 | 12 | 65 |
| 영원이 머문 역 | 850 | 310 | 16 | 85 |

각 지역에는 흔적 2종, 기억 2종, 영원 1종이 있습니다. 개별 추첨 가중치는 `6, 6, 3, 3, 1`입니다. 총합 19를 기준으로 각 확률은 31.58%, 31.58%, 15.79%, 15.79%, 5.26%입니다.

새 유물이 나오지 않은 탐사가 5회 연속이면 다음 탐사는 미발견 유물만 같은 가중치로 추첨합니다. 보정 카운터는 지역별로 보관됩니다. 따라서 지역 전체 수집은 최악의 난수에서도 유한한 탐사 횟수 안에 끝납니다. 이미 모두 모은 지역에서는 중복을 계속 얻습니다.

## 성장식

```text
유물 공명력 = 희귀도 기본치(18 / 26 / 36) + (복원 레벨 - 1) × 9 + 공명 단계 × 18
전체 공명력 = 기본 35 + 동행한 최대 3개 유물의 합
             + 발견한 유물 종류 × 4 + 초점 연구 단계 × 12
             + (서고지기 레벨 - 1) × 3

복원 잉크 비용 = floor(28 × 1.18^(현재 레벨 - 1) × 등급 계수)
등급 계수 = 1 / 1.2 / 1.5
복원 잔향 비용 = max(1, floor(현재 레벨 × 0.65))
복원 최대 레벨 = 20
공명 소모 기억 = 2 → 3 → 4, 최대 3단계

서고지기 레벨 = 1 + floor(sqrt(경험치 / 45))
```

성장 보정은 낮은 등급의 좋아하는 유물도 후반까지 쓸 수 있도록 설계했습니다. 높은 등급은 기본 공명력이 높지만 복원 비용이 조금 더 높습니다. 무작위 강화 실패나 장비 파괴는 없습니다.

## 연구와 휴식

- 기억의 초점: 10단계, 단계당 공명력 +12
- 섬세한 필사: 10단계, 단계당 탐사 잉크 +8%
- 잔향 채집: 8단계, 단계당 탐사 잔향 +10%
- 창가의 시간: 6단계, 단계당 휴식 잉크 +20%

첫 탐사 이후에는 분당 잉크 2개, 10분당 잔향 1개를 최대 8시간 모읍니다. 휴식 보상은 실제 경과 시간으로 계산하고 즉시 수령 시각을 저장하여 중복 수령을 막습니다. 미래·과거 시계 변경은 클라이언트 게임에서 완전히 방어할 수 없지만, 한 번에 받는 보상은 항상 상한을 적용합니다. 서버 순위표나 구매 경제에 연결하지 않습니다.

## 검증 결과와 해석

`npm run balance`는 서로 다른 시드 100개로 실제 게임 함수를 실행합니다. 자동 전략은 비용 대비 공명력이 좋은 복원·연구를 선택하고 여정 보상을 수령하며, 3회마다 미완성 지역을 다시 방문합니다.

조정 후 지역 해금 중앙값은 탐사 **0 / 3 / 9 / 23 / 48 / 78회**입니다. 30종 전체 수집은 중앙값 **90회**, 범위 **75~122회**였습니다. 이 수치는 최적화된 자동 전략의 탐사 횟수이며, 사용자 플레이 시간이나 재미를 입증하지는 않습니다.

초기 설계에서는 마지막 지역이 운에 따라 107~1295회에 열리는 문제가 확인되었습니다. 낮은 등급 동행 유물의 한계와 특정 유물 중복에 의존하던 문턱을 조정하여 64~113회로 줄였습니다. 후반에도 수집한 30종 전체의 복원, 공명, 34단계 연구가 남습니다.

실제 사용자 테스트에서 첫 10분 이탈, 어느 업그레이드를 선택하는지, 텍스트 가독성, 수집 완료 후 목표를 확인해야 합니다. 현재 수치가 장기 운영 밸런스의 최종 답이라는 가정은 하지 않습니다.

## 서고 수첩 확장 (v1.1)

- 도시 답사록: 지역별 3장, 총 18장의 별도 후일담. 누적 탐사 5/15/35회, 지역 수집 2/4/5종, 지역 유물 레벨 합 4/20/50을 모두 달성하고 앞 장부터 보상 수령. 기존 진행도 인정한다.
- 테마 전시: 서로 다른 지역의 유물 3개로 구성한 6종. 모두 수집 → 모두 Lv.5 → 모두 Lv.12, 총 18단계. 유물은 소모하지 않는다. 전시 3/9/18단계마다 칭호 성장. 수집 완료 뒤에도 여러 유물을 복원할 동기를 준다.
- 반복 의뢰: 지역 탐사 6회, 자유 탐사 8회, 복원 3회 중 하나를 수락. 수락 시 기준값과 보상을 저장하며, 이후 진행만 인정한다. 지역 의뢰는 열린 지역을 순환하고 해당 지역 기본 보상의 2배, 자유 탐사는 수락 당시 최상위 지역의 2배, 복원은 3배를 지급한다. 하나만 진행하며 취소 가능. 시간 제한·접속 연속 보너스 없음.
- 보상은 잉크와 잔향만 사용한다. 새로운 재화나 영구 능력 배율을 추가하지 않아 기존 공명력·확률 체계를 유지한다. 낮은 단계 유물 복원 의뢰가 초반 성장을 돕되, 이미 복원한 활동으로 의뢰를 반복 완료할 수 없다.
- 저장 버전 1에 선택 필드 notebook을 추가. 구형 저장은 비어 있는 수첩으로 이전하고 기존 유물·재화·탐사 기록을 보존한다. 신규 저장은 수첩 데이터와 수락 기준값을 검증한다.
- 검증: 기존 100개 시드 수집 여정과 10개 시드 수첩 완주 시뮬레이션, 보상 중복·이전 세이브·단계 조건 테스트, 모바일/PC 및 단독 HTML 브라우저 동작 확인.

## 가독성과 소녀 탐사 연출 (v1.2)

본문은 시스템 한글 고딕 계열 16px, 주요 버튼은 15~16px로 표시한다. 작은 메타 정보도 대부분 12px 이상을 유지하고, 어두운 녹색 글자로 대비를 높였다. 좁은 화면에서는 카드 수와 보상 배치를 조정해 글씨 크기를 유지한다.

사용자가 제공한 수채화 소녀를 바탕으로 제작한 투명 배경 이미지 `assets/explorer-sheet.png`는 출발·관찰·발견의 세 포즈를 담는다. 실제 2.8초 탐사 시간에 맞춰 포즈와 위치가 바뀌며, 연속 탐사와 화면 재렌더링에서도 경과 시간을 이어간다. OS 또는 게임 설정의 모션 줄이기를 따르고, 탐사 완료 후 기존 등급별 유물 발견 연출로 연결한다. 이미지는 미리 불러오고 오프라인 캐시에 포함하며, 단독 HTML에는 외부 요청 없이 사용할 수 있도록 한 번만 내장한다.

## 탐사 준비도와 보급 선택 (v1.3)

- 준비도 최대 10, 탐사 1회에 1 소모. 120초마다 1 회복하며 오프라인에서도 같은 규칙을 적용한다. 가득 찼을 때 초과 시간을 비축하지 않고, 부분 회복 시간은 다른 활동과 저장/불러오기 후에도 유지한다.
- 연속 탐사는 현재 준비도 안에서 최대 5회만 예약한다. 준비도 0에서는 출발을 막고 남은 회복 시간, 보급 비용, 수첩으로 이동하는 버튼을 보여 준다. 열린 화면에서도 회복 즉시 출발 버튼이 다시 활성화된다.
- 보급은 최대 3회분. 1회분마다 열린 최상위 지역 기본 잉크 보상의 3배를 소모하며, 가득 차기 직전에는 부족한 만큼만 계산한다. 최대 잉크 연구와 반복 탐사 의뢰를 포함한 탐사 수익보다 비싸므로 보급→탐사만으로 잉크를 무한 생산할 수 없다. 복원·연구와 보급 중 하나를 선택하는 비용을 만든다.
- 귀환 보상과 준비도 차감은 한 번에 저장한다. 탐사 중 새로고침하면 보상/차감 없이 취소된다. 이미 보상을 받은 탐사의 소모량은 새로고침으로 되돌아오지 않는다. 구형 세이브는 진행을 보존하고 준비도 10으로 이전한다.
- 무작위 유물 손실 대신 탐사 기회와 복원 자원의 기회비용을 사용한다. 기다리는 동안 수집품 복원, 전시, 답사록과 이야기를 정리할 수 있다.
- 밸런스 시뮬레이션은 준비도가 없으면 실제 회복 시간만큼 가상 시간을 진행한다. 기존 탐사 횟수 기준과 별도로 회복을 포함한 완주 시간을 출력한다.
