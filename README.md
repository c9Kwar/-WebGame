# 잔향 서고 · The Still Archive

시간이 멈춘 도시에서 유물을 찾고, 기억을 복원하는 한국어 수집형 성장 웹게임입니다. 빈티지 인쇄물과 아르데코, 초현실적인 도시의 정서를 담은 **독자적인 세계관·이야기·SVG 일러스트**를 사용합니다.

## 지금 플레이할 수 있는 기능

- 6개 탐사지, 30종 유물, 7편의 이야기
- 약 3초의 탐사, 수동 또는 5회 연속 탐사
- 3칸 동행, 20단계 확정 복원, 중복 유물로 3단계 공명
- 4개 분야·총 34단계 영구 연구, 9개 여정 보상
- 새로운 유물 6회 이내 확정 발견, 최초 탐사 신규 발견 보장
- 최대 8시간의 휴식 자원, 최근 30회 탐사 기록
- 브라우저 자동 저장, JSON 내보내기·가져오기, 손상 세이브 원본 보관
- 모바일 하단 탐색, 키보드 포커스, 움직임 줄이기, 선택형 발견 사운드
- 서비스 워커를 통한 최초 접속 이후 오프라인 플레이

현재 구현은 **완결된 단일 플레이어 정적 웹게임**입니다. 계정·클라우드 저장·멀티플레이·결제·서버 순위표는 없습니다. 진행은 현재 사이트 주소의 브라우저 저장소에 보관되므로 배포 주소를 옮길 때 세이브 파일을 내보내야 합니다.

## 실행

필요 도구: Node.js 22 이상, Python 3. 브라우저 테스트에는 Chromium이 필요합니다. 외부 npm 의존성은 없습니다.

```sh
cd /workspace/-WebGame
npm run dev
```

개발 서버 기본 포트는 8000입니다. `npm run dev`는 개발 서버이며 운영 배포에는 정적 호스팅을 사용합니다.

## 검증과 빌드

```sh
npm test                 # 게임 규칙·자원·저장 검증
npm run balance          # 100개의 결정론적 전체 플레이 시뮬레이션
npm run build            # dist/ 생성
npm run test:browser     # Chromium 실제 UI·모바일·저장·오프라인 검증
```

브라우저 검사는 자체 임시 HTTP 서버에서 `/game/` 하위 경로로 실행되어 GitHub Pages 프로젝트 경로를 함께 검증합니다. Chromium 위치가 다르면 `CHROMIUM_PATH`를 지정합니다. 결과와 스크린샷은 `artifacts/`에 저장됩니다. 이 환경에서는 `--dump-dom` 대신 CDP를 사용합니다.

## 사이트 공개

`npm run build`는 **`dist/잔향서고.html`**도 만듭니다. 이 파일은 CSS·그림·게임 코드를 모두 포함하므로 파일을 내려받아 브라우저에서 열기만 해도 플레이할 수 있습니다. 별도 서버나 인터넷 연결이 필요하지 않습니다. 파일로 실행한 진행과 공개 사이트의 진행은 서로 다른 저장소를 사용하므로 이동할 때 세이브 내보내기·가져오기를 이용하세요.

`dist/` 폴더를 GitHub Pages, Cloudflare Pages, Netlify 등의 정적 호스팅에 그대로 게시할 수 있습니다. 루트와 하위 경로 배포를 모두 지원합니다.

### GitHub Pages

1. `c9Kwar/-WebGame` 저장소에 코드를 `main` 브랜치로 업로드합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `.github/workflows/pages.yml` 워크플로를 실행합니다. 테스트와 밸런스 검사를 통과한 `dist/`만 게시합니다.
4. Actions의 배포 결과에 표시된 주소에서 페이지와 탐사 동작을 확인합니다.

워크플로 파일이 존재하는 것만으로 실제 게시가 완료되지는 않습니다. 공개 여부는 실제 배포 결과와 HTTP 응답으로 확인해야 합니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/data.js` | 탐사지, 유물, 희귀도, 연구, 보상, 이야기 |
| `src/game.js` | DOM과 분리된 게임 규칙·경제·저장 검증 |
| `src/art.js` | 독자적인 도시 풍경과 유물 SVG, 아이콘 |
| `src/app.js` | 화면, 탐사 타이머, 저장·복원, 설정, 접근성 |
| `style.css` | 반응형 아르데코 서고 UI |
| `sw.js` | 네트워크 우선 오프라인 캐시 |
| `tests/` | 단위 검사, 전체 플레이 시뮬레이션, 실제 브라우저 검사 |

상세 밸런스는 [게임 설계](docs/GAME_DESIGN.md), 장기 확장 계획과 현재 한계는 [구조 설계](docs/ARCHITECTURE.md)를 참고하세요.
